# NARFKIT

Platform belajar IoT & AI untuk siswa dan guru.

## Halaman

| Halaman | File | Pengguna |
|---|---|---|
| Landing page | `landingpage.html` | Umum |
| Dashboard siswa | `dashboardsiswa.html` | Siswa |
| Course | `course.html` | Siswa |
| Simulation: Wokwi | `simulation.html` | Siswa |
| Simulation: Teachable Machine | `teachablemachine.html` | Siswa |
| Chatbot | `chatbot.html` | Siswa |
| Dashboard guru | `dashboardguru.html` | Guru |
| Class / Monitoring / Grading | `class.html`, `monitoring.html`, `grading.html` | Guru |

Style umum (warna tema, navbar) ada di `global.css`; tiap halaman punya CSS sendiri.

## Dokumentasi fitur
- [Teachable Machine Simulation](docs/TEACHABLE_MACHINE.md): uji model Teachable Machine pakai webcam atau ESP32-CAM.

## Menjalankan secara lokal
Buka lewat web server lokal (mis. VS Code *Live Server* atau `npx http-server`),
jangan dobel-klik file HTML, agar fitur kamera bisa berjalan.
